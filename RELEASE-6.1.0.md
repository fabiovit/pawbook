# PawBook v6.1.0 – DOMOTICA UI & Repository Quality

PawBook 6.1.0 aligns the application shell with the updated DOMOTICA dashboards.

## New application shell

- Sticky translucent header based on Inverter Dashboard.
- Home Assistant hamburger menu on mobile.
- PawBook icon, name and version grouped in the top-left area.
- Ko-fi **Supporta il progetto** action on the right.
- Compact icon + text section menu directly below the header.
- Native horizontal scrolling on smartphones.
- Cleaner desktop and mobile geometry.

All existing PawBook health, ENCI, genealogy, Multi-Pet and reminder features are preserved.

## Repository quality

PawBook now includes:

- HACS Action validation;
- Hassfest validation;
- Release badge;
- HACS Custom badge;
- Validate status badge;
- Hassfest status badge;
- MIT license badge.

The GitHub Actions run on pushes, pull requests, scheduled checks and manual execution.
