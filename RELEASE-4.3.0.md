# 🐾 PawBook v4.3.0 – Treatments Center

PawBook 4.3.0 transforms the Treatments section into a dedicated center for medications and therapies.

## 💊 Treatments Center

- Dedicated dashboard for treatments and medications.
- Separate counters for active, scheduled and completed therapies.
- Quick view of the next scheduled treatment.
- Dosage and frequency shown directly in each treatment card.
- Start and end dates always visible.
- Active therapies with a defined end date display a progress bar and current treatment day.
- Notes remain immediately accessible.
- Existing treatment records remain editable and removable.

## 📎 Treatment attachments

PDF files and images can now be linked directly to an individual treatment, making it easier to keep prescriptions, therapy plans and related documents together with the corresponding record.

## 📱 Mobile

The Treatments Center includes a responsive single-column layout with touch-friendly actions for smartphone use.

## 📚 Documentation

- Reworked the main README in English.
- Added `README.it.md` with complete Italian documentation.
- Added a Ko-fi support section.

## 🔒 Compatibility

Existing PawBook records, ENCI information, genealogy, vaccinations, veterinary visits, photos, backups and attachments are preserved.
