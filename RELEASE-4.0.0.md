# 🐾 PawBook v4.0.0 – Next Generation

PawBook 4.0 begins a new generation of the interface, focused on making the information that matters most immediately understandable rather than presenting medical data as simple lists.

## New Home overview

- New health-oriented dashboard shortcuts.
- Immediate access to Smart Health, vaccinations, visits and genealogy.
- Clearer status information directly from the main overview.

## New Vaccination dashboard

The Vaccinations section has been completely rebuilt.

- Vaccinations are grouped by vaccine name.
- Every recorded vaccination is visible: PawBook no longer limits this section to the latest five entries.
- Expandable full history for each vaccine.
- Latest dose and next recall shown directly on each card.
- Status badges for in-order, expiring and expired vaccines.
- Summary counters at the top of the section.
- Existing edit and delete controls are preserved for every individual dose.

## Compatibility

- Existing PawBook data is preserved.
- ENCI import and pedigree remain unchanged.
- HD / ED / DNA information remains unchanged.
- Smart Health, calendar, attachments, reports and backup remain available.
- Desktop and smartphone layouts remain supported.

## Updating

Restart Home Assistant completely after installing the update. If the previous interface remains visible, refresh the browser or Home Assistant app frontend.
