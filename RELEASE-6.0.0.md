# PawBook v6.0.0 – Multi-Pet Hub

PawBook 6.0 introduces a true multi-pet experience for households with more than one dog.

## PawBook Family

When multiple pets are configured, PawBook now shows a family dashboard before the selected pet record.

Each pet card includes:

- photo;
- name and breed;
- current weight;
- next vaccination;
- number of current reminders.

Selecting a pet immediately opens that pet's individual PawBook record.

## Family reminders

PawBook now aggregates automatic reminders across all pets.

The Family Hub shows the most important reminders together while always identifying the pet they belong to. Selecting a reminder switches to the correct pet and opens the relevant section.

## Shared health agenda

Upcoming health events from every configured pet are combined into one family agenda.

This includes:

- vaccination recalls;
- treatment start/end events;
- estimated heat-cycle events.

Selecting an event opens the calendar for the correct pet.

## Data separation

PawBook 6.0 does not merge pet records.

Each animal continues to use its own Home Assistant config entry and keeps separate:

- profile;
- health records;
- vaccinations;
- visits;
- treatments;
- weight;
- heat cycles;
- ENCI data;
- genealogy;
- attachments;
- backups.

The Multi-Pet Hub only aggregates the information needed for the family overview.

## Compatibility

All PawBook 5.0 features remain available for every individual pet.
