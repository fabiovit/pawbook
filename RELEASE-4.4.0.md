# 🐾 PawBook v4.4.0 – Weight Center

PawBook 4.4.0 transforms weight tracking into a complete dashboard designed to make long-term changes easier to understand.

## ⚖️ Weight Center

- New dedicated Weight Center dashboard.
- Current weight with the date of the latest measurement.
- Difference from the previous measurement.
- Total variation across the recorded history.
- Average, minimum and maximum weight.
- Extended interactive weight trend chart.
- Complete weight history grouped by year.
- Notes remain visible alongside every measurement.
- Existing records can still be edited or deleted directly from the dashboard.

## 📱 Responsive interface

The Weight Center adapts automatically to desktop, tablet and smartphone layouts.

## 🔒 Data compatibility

No existing PawBook data is removed or migrated. Existing weights, vaccines, visits, treatments, ENCI information, genealogy, attachments and photos are preserved.
