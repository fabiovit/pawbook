# 🐾 PawBook v1.1.2

This maintenance release fixes a black-screen regression introduced in v1.1.1.

## Fixed

- Corrected the mismatch between the Home Assistant panel element name and the JavaScript custom element.
- Added a new versioned frontend file to bypass stale browser and Home Assistant cache.
- Restored normal PawBook panel loading.

## Included

- Green **Vivo** status indicator.
- Improved fourth-generation pedigree cards.
- Clickable ancestor cards with detailed popup.
- Italian `DD/MM/YYYY` date formatting.
- Local dog photo support.

## Updating

Restart Home Assistant completely after installing the update. Then refresh the browser page.
