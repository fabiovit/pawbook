# PawBook v6.10.4 – Distribution Hotfix

PawBook v6.10.4 is a distribution and versioning hotfix based on the approved v6.10.3 Health Control Center build.

## What changed

- Preserves the complete PawBook v6.10.3 UI and functionality.
- Updates the integration version to `6.10.4`.
- Keeps the stable `pawbook-panel-v630.js` frontend base.
- Aligns the visible frontend version with the integration manifest.
- Provides a clean version for GitHub/HACS distribution after the previous v6.10.3 tag pointed to older repository contents.

## Included from v6.10.3

- Health Control Center
- Multi-page navigation
- Dedicated Weight, Vaccination, Veterinary, Treatment and Heat Cycle pages
- Clear Add / Edit / Delete actions
- Large pet photo dashboard
- Redesigned Agenda
- Improved ENCI and Genealogy
- Diagnostics area
- Large typography and improved readability
- Responsive desktop and mobile layout
- Recorder-safe sensor attributes

## Update notes

After updating through HACS:

1. Restart Home Assistant.
2. Perform a forced browser refresh if the previous PawBook frontend is still cached.
