# 🐾 PawBook v2.0.1 – Mobile Responsive Update

This maintenance release brings a dedicated smartphone experience to PawBook 2.0.

## 📱 Mobile improvements

- Redesigned the dog profile card for narrow screens.
- Switched dashboard summaries and statistics to mobile-first layouts.
- Added touch-friendly horizontally scrollable navigation.
- Improved spacing, typography and controls for phone displays.
- Added iPhone and Android safe-area support.
- Increased touch targets for buttons and interactive controls.

## 🌳 Genealogy on smartphone

- Added a dedicated horizontally scrollable pedigree view.
- Keeps parent/ancestor relationships readable instead of shrinking the desktop tree.
- Compact fourth-generation cards remain tappable.
- Ancestor details open in a phone-friendly dialog.

## 💬 Dialogs and forms

- Mobile dialogs now behave like full-width bottom sheets.
- Sticky headers and action buttons remain accessible while scrolling.
- Form inputs use phone-friendly sizing and avoid iOS input zoom.

## ❤️ Health and ENCI

- Improved the health timeline on small screens.
- ENCI panels collapse cleanly to a single column.
- Record edit/delete controls remain easy to reach.

## Compatibility

All PawBook 2.0 data and features are preserved, including ENCI import, pedigree, HD/ED/DNA information, health records, backups and dog photos.

After updating, restart Home Assistant completely and refresh the mobile app or browser.
