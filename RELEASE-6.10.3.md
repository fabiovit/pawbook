# PawBook v6.10.3 – Health Control Center

PawBook v6.10.3 introduces a major interface redesign focused on readability, navigation and health-data management.

## Highlights

- New Health Control Center
- New multi-page navigation
- Dedicated management pages for Weight, Vaccinations, Veterinary visits, Treatments and Heat cycles
- Clearer Add / Edit / Delete controls
- Redesigned Dashboard with larger pet photo and stronger visual hierarchy
- Improved Agenda
- Improved ENCI and Genealogy sections
- New Diagnostics area
- Significantly larger typography across the interface
- Improved desktop, tablet and mobile responsiveness
- Stable `pawbook-panel-v630` frontend base retained
- Recorder-safe sensor attributes preserved

## Health Control Center

Health data is now organized into dedicated modules instead of one long management page.

Each section provides direct access to records and CRUD actions while keeping the interface cleaner and easier to navigate.

## ENCI & Genealogy

ENCI data and genealogy remain fully integrated, with a clearer and more readable presentation.

## Responsive UI

The interface has been refined for desktop and mobile use, with particular attention to typography, spacing and navigation.

## Update notes

After replacing the custom component, restart Home Assistant once and perform a full browser refresh.
