# PawBook v6.5.1 – Safari Frontend Hotfix

PawBook 6.5.1 fixes a frontend loading regression introduced in v6.5.0.

## Fixed

- Fixed a completely white PawBook screen on Safari.
- Removed the top-level `await import(...)` bootstrap that Home Assistant loads as a classic script and Safari rejects with `SyntaxError: Unexpected keyword 'import'`.
- Replaced it with a classic-script-compatible loader for the PawBook v640 base panel.
- Preserved the v6.5 navigation redesign, the new **Gestione** menu and the spacing cleanup.

## Notes

The separate `chronos-timeline` duplicate custom-element error is not generated by PawBook and is unrelated to this hotfix.
