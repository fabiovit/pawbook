# 🐾 PawBook v2.0.0 – Major Release

PawBook 2.0 trasforma il pannello in una vera dashboard sanitaria per il cane, mantenendo piena compatibilità con i dati delle versioni 1.x.

## Novità

- Timeline sanitaria unificata.
- Età calcolata automaticamente.
- Statistiche rapide su peso, vaccini, visite e terapie.
- Backup completo e ripristino tramite file JSON.
- Navigazione PawBook 2.0 ampliata.
- Supporto multi-cane preservato.
- ENCI, genealogia fino alla quarta generazione e dati HD/ED/DNA preservati.
- Foto del cane e date italiane preservate.

## Aggiornamento

Dopo l'installazione riavvia completamente Home Assistant e ricarica il browser. I dati PawBook esistenti non vengono cancellati o migrati in un formato incompatibile.
