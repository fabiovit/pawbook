# PawBook v4.5.0 – ENCI Pro

PawBook 4.5.0 transforms the ENCI area into a richer dashboard while preserving the existing import workflow and genealogy.

## Highlights

- New ENCI Pro profile overview.
- HD and ED results at a glance.
- DNA / biological sample status.
- Pedigree ancestor counter.
- Dedicated official ENCI health section.
- Improved official event presentation.
- Responsive smartphone layout.
- Existing desktop pedigree and mobile genealogy preserved.
- Full compatibility with existing PawBook data.
