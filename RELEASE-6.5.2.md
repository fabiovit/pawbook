# PawBook v6.5.2 – Gestione Menu Hotfix

PawBook 6.5.2 fixes the Gestione navigation menu in Safari and the Home Assistant panel context.

## Fixed

- Replaced the native details/summary control with an explicit JavaScript-driven menu button.
- Fixed cases where Gestione did not open.
- Added reliable open/close behavior on desktop and mobile.
- Management items close the menu and open the selected PawBook section.

## Preserved

All PawBook Health OS, Smart Health, Agenda, ENCI, Multi-Pet, genealogy, documents, reports and backup features remain unchanged.
