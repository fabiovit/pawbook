# PawBook v6.3.0 – Structural Visual Redesign

PawBook 6.3.0 is the real visual redesign.

Unlike 6.2.0, this release changes the page structure, not only its CSS.

## Highlights

- Main KPIs are now integrated directly into the pet profile hero.
- Profile actions use a compact toolbar.
- Desktop content uses a two-column application layout.
- Smart Dashboard is rendered as one unified status matrix.
- Nested card-on-card layouts are reduced across health sections.
- Mobile keeps the same information hierarchy with a cleaner vertical flow.
- DOMOTICA / Inverter header and navigation are preserved.
