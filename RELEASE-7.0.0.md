# PawBook v7.0.0 – Clean Major Release

PawBook v7.0.0 is a clean major release that consolidates the latest approved PawBook interface and removes obsolete project files accumulated across previous versions.

## Highlights

- Health Control Center
- Multi-page navigation
- Weight Center
- Vaccination Center
- Veterinary Center
- Treatments Center
- Heat Cycle Center
- Agenda
- ENCI
- Genealogy
- Diagnostics
- Large typography
- Responsive desktop and mobile interface
- Home Assistant theme-aware light/dark mode
- Recorder-safe sensor attributes

## Cleanup

- Removed obsolete frontend assets
- Removed historical release-note files
- Removed old publication helper files
- Removed cache and temporary files
- Consolidated the frontend into one asset: `pawbook-panel-v700.js`

## Theme handling

PawBook follows the active Home Assistant theme directly via `hass.themes.darkMode`.

## Update notes

After replacing the integration:

1. Restart Home Assistant.
2. Open PawBook.
3. If needed, perform a forced browser refresh once.
