# PawBook v1.0.1

Questa release migliora la leggibilità dell’albero genealogico e uniforma tutte le date al formato italiano.

## Correzioni

- Quarta generazione più larga e leggibile, con scorrimento orizzontale.
- Nomi degli antenati non più spezzati lettera per lettera.
- Tutte le date vengono visualizzate come `GG/MM/AAAA`.
- Corrette le date ENCI ISO con componente oraria.
- Nuovo asset frontend per evitare problemi di cache dopo l’aggiornamento.

Dopo l’installazione, riavvia completamente Home Assistant.
