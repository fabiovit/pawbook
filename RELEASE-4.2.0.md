# 🐾 PawBook v4.2.0 – Veterinary Center

PawBook 4.2.0 transforms the veterinary visits section into a complete Veterinary Center.

## 🩺 New Veterinary Center

- Complete veterinary visit dashboard.
- Last visit and days-since-last-visit overview.
- Total visit, veterinarian, category and attachment counters.
- Full veterinary timeline grouped by year.
- Automatic visit categories for controls, diagnostics, exams, specialist visits and surgery.
- Complete outcome and notes displayed in the timeline.
- Edit and delete actions remain available for every record.

## 📎 Visit attachments

PDF files and images can now be attached directly to a specific veterinary visit.

Attachments remain stored locally in PawBook and are included in PawBook backups.

## 🔒 Compatibility

Existing PawBook data is preserved. No migration or manual data conversion is required.

The ENCI integration, genealogy, Vaccination Center, Smart Health, calendar, reports and mobile interface remain unchanged.

## Updating

1. Install PawBook v4.2.0.
2. Restart Home Assistant completely.
3. Refresh the PawBook panel if the previous frontend is still cached.
