# 🐾 PawBook v4.1.0 – Vaccination Center

PawBook 4.1 introduces a redesigned Vaccination Center focused on clarity, complete long-term history and upcoming recalls.

## New
- Dedicated vaccination status overview.
- Total vaccination doses and vaccine-type counters.
- Latest administered dose and next recall at a glance.
- Vaccines grouped by type with complete expandable history.
- Clear In regola / In scadenza / Scaduto status for every vaccine.
- Detailed dose information including veterinarian, batch, recall date and notes.
- One-tap new-dose button that automatically pre-fills the vaccine name.

## Preserved
- All existing vaccination records, including older doses.
- Smart Health, ENCI, genealogy, attachments, calendar and backup features.
- PawBook 4.0 stored-data compatibility.

## Updating
1. Install the update.
2. Restart Home Assistant completely.
3. Refresh the browser or Home Assistant app if the previous frontend is still cached.

No existing PawBook data is deleted or migrated by this update.
