# 🐾 PawBook v1.2.2

This release refreshes the PawBook overview with a cleaner, more app-like dashboard while preserving all existing health, ENCI and genealogy features.

## New dashboard

- Larger PawBook header and integrated paw identity.
- Redesigned dog profile card with larger photo and clearer identity data.
- Three prominent summary cards for current weight, next vaccination and latest visit.
- New visual navigation bar for Panoramica, Salute, Vaccini, Visite, Genealogia, ENCI and Impostazioni.
- Navigation buttons smoothly jump to the corresponding PawBook section.
- Improved desktop and mobile spacing and responsiveness.

## Preserved

- ENCI pedigree import and pedigree health data.
- HD / ED / DNA ancestor information.
- Dog photo upload.
- Italian DD/MM/YYYY date formatting.
- Existing health records, genealogy and locally stored data.

## Updating

Restart Home Assistant completely after installing the update. If the old interface remains visible, refresh the browser once.
